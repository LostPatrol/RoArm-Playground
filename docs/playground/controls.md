# 机械臂控制

关节面板保留数值、±5°与到位按钮，并增加四轴实时滑条。灯光滑条同样立即发送；浏览器首次35毫秒合并最新目标，后续发送间隔60毫秒，只保留一个在途滑条请求，避免拖动结束后依次执行过时目标。停止和离开网页清除待发目标，后台请求序号拒绝迟到运动。界面展示的角度与三维模型仍来自串口反馈。

手动控制时物品、泡沫、人脸、颜色、标记及框选识别继续运行。自动跟随模式收到手动运动后暂停自动运动、保留检测；在该实验重新启动跟随即可恢复。语音、手势、拍手和IMU会发动作，因此手动控制接管时停止这些模式。动作程序运行中请先停止再手动控制。

展开“原厂控制与命令”可使用 Torque ON/OFF、自适应力矩 ON/OFF、XYZ绝对坐标、前后/左右/上下相对运动及夹爪角增量。坐标单位毫米、夹爪输入单位度；后台转换到厂家T104的弧度。默认使用实测夹爪角；坐标先按厂家连杆尺寸与关节限制校验，再调用固件IK。目标可达不等于已准确到位，观察实测XYZ和关节角。

“回到初始位”采用原厂INIT：`T102 base=0 shoulder=0 elbow=1.5707965 hand=3.1415926 spd=0 acc=0`，其中0速度/加速度表示固件最大速度。Torque使用T210；DEFA使用T112与原厂b60/s110/e50/h50阈值。初始状态未知时不伪造开关状态。Torque OFF后机械臂失去主动支撑，需现场人员托住；网页不会启动时自动切换力矩或自适应力矩。

字符串入口发送单个JSON对象，点击展开厂家命令示例。保留既有重启/Flash清空/BOOT重置屏蔽；其他命令直接发串口，响应区显示实际发送或T105反馈。原始命令会改变机械臂或配置，依据厂家协议使用。

数字机械臂按厂家连杆长度和126毫米基座绘制，修正俯视透视与深度遮挡。拖动背景旋转视角；选择水平或垂直平面后拖动橙色夹爪柄，屏幕射线与所选平面交点转换为真实XYZ目标，经T104同步实体机械臂。橙色虚线是拖动目标，实体姿态只随实测反馈变化；不可达目标明确报错。模型是运动几何示意，未作高精度标定。

上位机手势、猜拳和语言导演面板提供“尝试连接/加载”入口，默认寻找浏览器所在电脑的8082管理服务，也可填写另一台上位机地址。安装方法见[上位机说明](host.md)。加载模型不自动开始互动；待推理在线后再选择实验启动。
