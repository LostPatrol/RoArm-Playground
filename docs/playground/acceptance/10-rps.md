# 和机器人猜拳

现场状态：**待实测**。最终结论统一以 [状态表](../status.md) 为准；本文列验收方法，不预先宣布通过。

## 目的

用真实手势输入与随机机器人出拳完成一局游戏，验证三种胜负规则。

## 所需物品与前置

按 [host.md](../host.md) 启动 gestures worker，准备张手/握拳/V 三种手势；摄像头清楚看见手部。

## 网页操作

1. 打开“猜拳”并启动，握拳保持片刻，记录玩家 rock、机器人的出拳及胜负。石头/布/剪刀按钮是手动注入调试输入，不能计作摄像头手势识别。
2. 放下手后再次出拳，重复张手 paper、V scissors。
3. 保持同一手势，确认不会连续每帧增加新局。
4. 对照 rock胜scissors、paper胜rock、scissors胜paper及平局规则，观察灯光回应。

## 通过标准

真实手势驱动实际局次；所有已观察组合的胜负正确，持续保持同一手势只触发一次，释放后可再玩。当前机器人出拳显示在网页，实体以灯光回应；如新增动作，另记录实际效果。

## 自动测试

在项目根目录使用项目 `.venv/bin/python`。

运行 `.venv/bin/python -m unittest discover -s tests -p test_host_worker.py -v` 验证手势稳定和模式隔离；运行完整套件复测后端猜拳规则。随机出拳概率不能用单局结果检验。

## 现场未验收

现场三手势识别、各胜负组合显示和实体回应待实测。

## 失败定位

没有开局：确认 mode=rps、手势置信度和三帧稳定。不断重复：检查 worker 去抖和放手动作。结果错误：保留 player/robot/outcome 原始状态定位规则；网页出拳不可描述为夹爪真的比出三种形状。
