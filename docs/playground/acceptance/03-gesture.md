# 手势遥控

现场状态：**待实测**。最终结论统一以 [状态表](../status.md) 为准；本文列验收方法，不预先宣布通过。

## 目的

通过真实手势分类控制夹爪、底座或灯光，区分图像识别与人工按钮输入。

## 所需物品与前置

演示笔记本安装上位机依赖与 MediaPipe gesture 模型；摄像头能看清整只手。按 [host.md](../host.md) 启动 `host/worker.py --mode gestures --server <RK网页地址>`，必须使用项目 Python。

## 网页操作

1. 打开“手势遥控”，点击“连接并加载本机手势模型”，确认模型就绪与worker在线；默认查找浏览器所在电脑的8082，也可填写上位机地址。管理服务未安装时按[host.md](../host.md)安装，缺模型时界面给出路径与下载命令。加载本身不启动机械臂模式。
2. 点击启动，依次张手、握拳、比 V、拇指上、拇指下；每次保持片刻后放下手。拇指上下是项目约定的左右控制按钮，不代表真实空间左右方向检测。
3. 对照页面说明，观察夹爪姿态、灯光及左右底座动作。
4. 保持一个手势不动，检查不会每帧反复触发；切换其他项目后再次出手势。

## 通过标准

真实模型输出手势与置信度；稳定手势触发一次对应动作，放下再出可再触发。模式切换后旧手势 worker 不操纵其他项目；运动效果大致可见即可。

## 自动测试

在项目根目录使用项目 `.venv/bin/python`。

运行 `.venv/bin/python -m unittest discover -s tests -p test_host_worker.py -v`，验证稳定帧、释放、低置信度及模式隔离。真实模型可先用 `--image <真实手势照片> --dry-run`，此操作不向机械臂发送动作。

## 现场未验收

真实学生手势、距离、遮挡、模型置信度和夹爪映射待实测。

## 失败定位

worker 不在线：检查模型文件、依赖和 --server。识别持续不稳：调整光照和手距、完整展示手部。识别正确但动作异常：核对模式和串口反馈；以实机确认夹爪角度方向。
