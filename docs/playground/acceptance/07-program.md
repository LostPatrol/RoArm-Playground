# 图形化动作编程

现场状态：**待实测**。最终结论统一以 [状态表](../status.md) 为准；本文列验收方法，不预先宣布通过。

## 目的

排列有限动作积木，体验顺序、等待、重复和识别条件。

## 所需物品与前置

浏览器、串口及摄像头；准备灯光、底座小角度等简单动作。条件示例需要对应人脸/彩卡/标记。

## 网页操作

1. 打开“图形编程”，依次添加灯亮、等待、底座小角度动作和灯灭。
2. 调整顺序，输入程序名，保存后运行。
3. 增加重复；确认重复次数与日志一致。
4. 增加“检测到人脸/颜色/标记”条件，分别用有目标和无目标场景测试。
5. 运行后中途停止，并检查后续积木未执行。

## 通过标准

界面编辑的数据与保存列表一致，执行顺序、等待、重复和条件效果可解释；未满足条件时跳过相应子步骤。实体明显按预期方向运动即可，不能要求精密轨迹。

## 自动测试

在项目根目录使用项目 `.venv/bin/python`。

运行 `.venv/bin/python -m unittest discover -s tests -v`，查看 validate_steps 对未知类型、越界角度、重复/嵌套和等待范围的检查。自动模拟不能代替实体执行。

## 现场未验收

图形编辑实际浏览器交互、条件场景、保存与实体程序运行待实测。

## 失败定位

拒绝保存：检查数值、空步骤及嵌套限制。条件一直不成立：先用独立视觉项目验证检测。动作抢占：先停止现有程序再手动控制；查看事件序列定位具体步骤。
