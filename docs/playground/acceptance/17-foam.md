# 黑色泡沫识别与抓取尝试

现场状态：**待实测**。最终结论统一以 [状态表](../status.md) 为准；本文列验收方法，不预先宣布通过。

## 目的

先验证桌面观察与黑块检测；抓取必须以物体实际离桌的可见证据验收。

## 所需物品与前置

黑色泡沫、受控绿色桌面/垫，人工确认可见桌面的观察姿态、机械臂空间及夹爪可达关系。当前视觉使用低饱和度和亮度轮廓候选，没有材质识别、深度或手眼标定。默认 `max_saturation=100`、`dark_threshold=220`；自动曝光可能让黑泡沫看起来灰亮，不能坚持用 V<65/95 判断所有黑物。

可用模式参数 `roi:[0,0.35,1,0.65]` 排除顶部杆件；ROI 是完整画面内归一化 x/y/w/h，检测框仍用原图坐标。ROI需要结合当前相机姿态确认，不能把这次桌面区域假定为所有姿态通用。

V220现在是上限，实际门槛取ROI内亮度75分位的0.88倍与上限的较小值，可查看 `parameters.effective_dark_threshold`；浅色低饱和空桌面不再仅因V<220而入选。分数是轮廓/凸包面积比，避免斜视块只占轴向框一半而低分，不是识别泡沫的概率。其他暗物、键盘仍可能成为候选。

## 网页操作

1. 打开“黑泡沫抓取”，将泡沫放入真实视野，核对 dark_foam_candidate 框。
2. 移走泡沫或放其他暗物，说明算法局限。
3. 为同一固定物体位置，先人工确认并分别“记录观察姿态”“记录接近姿态”“记录抬起姿态”；缺少 observe/approach/lift 任意一点时，抓取入口应禁用或明确拒绝。未确认接近姿态时不启动定点抓取。
4. 三点完整且现场确认可达后，再“尝试定点抓取”，对照观察、接近、闭爪和抬起的实际过程。这是人工示教固定点尝试，不能改称任意视觉目标自动抓取。
5. 抓取阶段用侧面录像记录夹爪与桌面，保存物体离桌和持续夹持证据。

## 通过标准

识别子项：框对应实际块并明确标为候选，改变曝光后如实记录参数/误检。抓取子项：同一次完整过程实际夹住目标，目标清楚离开桌面并保持，不以舵机角度到位、夹爪空合或目标被推走算成功。三点记录完整只意味着定点流程可启动，不表示实际夹起已通过；物体移动后要重新确认接近点。

## 自动测试

在项目根目录使用项目 `.venv/bin/python`。

运行 `.venv/bin/python -m unittest discover -s tests -p test_vision.py -v`，验证候选位置、曝光后亮度170的物体、饱和度过滤、ROI全图坐标和整幅暗图75%过滤。设置 `ROARM_FOAM_REAL_IMAGE=agent/codex/task02-extended/desktop-observe-135.jpg` 运行同套件，以真实绿色桌面照片回归目标框与实物范围重叠大于85%；照片保持在本地过程目录，不入公共仓库。这些测试只证明CV算法；不能证明接近、接触或抓取。

## 现场未验收

task3用户截图的回归可设置 `ROARM_FOAM_TASK3_IMAGE=agent/task/assets/image-20261009031857444.png`；测试中央实块仍检出且大面积左侧空桌面框消失，属于离线原图回归，不是新一轮现场验收。曝光阈值和形状分数变化须结合原图看，不单按分数判材质。

已取得肘部约135°观察姿态下的真实桌面照片，能看到泡沫；新版算法在该照片检出约x148..432、y250..480范围的实际块。该单图回归不是抓取成功。人工接近/抬起点尚未完成验证，泡沫硬度、夹爪接触、几何关系和真实离桌证据仍待实测；抓取仍属开发项，最终状态以集中状态表为准。

## 失败定位

无框：先确认相机真能看见桌面与泡沫，再观察自动曝光后的S/V并调 `max_saturation` 与 `dark_threshold`；真实黑块可能并不低亮度。杆件误检：设置合适ROI，并用原图核对目标。灰色桌面或其他低饱和物也可能误检，该阈值是受控场景选择，不代表普适材质检测。框稳定但抓不到：检查相机/夹爪/桌面几何与三个人工姿态，不能把画面归一化坐标直接当机械臂坐标。需人工协助项集中记入状态/阻塞清单。
