# 魔法指挥棒

现场状态：**待实测**。最终结论统一以 [状态表](../status.md) 为准；本文列验收方法，不预先宣布通过。

## 目的

验证 HSV 颜色检测与水平/俯仰随动，展示改变参数怎样改变机器人行为。

## 所需物品与前置

红、蓝、绿或黄彩卡，浅色背景和摄像头；初次选择较大色块。不要让同色衣服占据大部分画面。

## 网页操作

1. 打开“彩色指挥棒”，选与彩卡相同的颜色。
2. 先只观察色块框，缓慢移动到左、右和中央。
3. 换颜色：原目标应消失；修改颜色选择后应检出新卡。
4. 启用双轴随动，连续左右/上下移动，再移出彩卡；最后停止项目。手动调关节期间应继续识别，但自动运动暂停，重新启动跟随恢复。

## 通过标准

框与实际大色块对应，颜色切换生效，小噪点不驱动持续动作；机械臂大致朝目标转动。目标丢失后不继续按旧框转动；无需精细定位。

## 自动测试

在项目根目录使用项目 `.venv/bin/python`。

运行 `.venv/bin/python -m unittest discover -s tests -p test_vision.py -v`，覆盖红色色相两端、颜色切换、小点过滤与自定义 HSV。

## 现场未验收

现场彩卡、同色背景、光照变化及运动方向待实测。

## 失败定位

错误对象被选：减少同色背景或增大面积阈值。无框：检查颜色选择和实际色相；调 HSV 时 H 是 0..179。随动抖动：先确认目标框稳定，记录视频模糊与背景干扰；默认以实测角为基线、约100ms刷新、4%画面死区、速度500steps/s，不等待到位。实际刷新受推理/串口耗时限制，不能仅凭参数宣称10Hz实测通过。
