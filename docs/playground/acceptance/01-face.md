# 寻找观众、亮灯致意

现场状态：**待实测**。最终结论统一以 [状态表](../status.md) 为准；本文列验收方法，不预先宣布通过。

## 目的

验证真实人脸检测、水平寻找、上下俯仰跟随及亮灯点头致意，理解“检测→选择目标→执行动作”。

## 所需物品与前置

摄像头、串口实测反馈、正常光照、一名观众；YuNet 模型可用，实际后端应显示 YuNet OpenCV DNN CPU。Haar 仅作显式备用，已有无人墙面/桌椅误检历史，不能把备用检测当人脸已通过。先选择末端朝前的观察姿态，避开线缆遮挡；初次仅识别，随后小范围随动。

## 网页操作

1. 打开“寻找观众”，行为先选“只识别”并启动，先观察无人墙面应无框。
2. 正面对摄像头，连续左右/上下移动，随后离开画面。
3. 启用运动，观察底座寻找、双轴跟随、亮灯和点头；致意期间识别继续、跟随暂停，完成后保持face模式继续跟随。离开画面超过2秒再回来可再次致意，两次至少间隔8秒。
4. 点击停止，确认模式退出；保留事件记录和实体录像。

## 通过标准

框随真实脸部变化；离开后框消失。随动能大致朝向观众；检测居中后出现致意动作和真实关节反馈。不要求小于 1° 的到位精度。停止后不继续追加搜索动作。

## 自动测试

在项目根目录使用项目 `.venv/bin/python`。

运行 `.venv/bin/python -m unittest discover -s tests -p test_vision.py -v`，检查空白画面无脸。设置 `ROARM_VISION_FACE_IMAGE` 用真实人像测试，设置 `ROARM_VISION_EMPTY_IMAGE` 用真实无人画面回归，必须实际使用 YuNet。模型测试不能证明实机寻找和点头通过。

## 现场未验收

现场人脸距离、光照、随动方向、扫描空间、点头动作和串口反馈仍待实测。

## 失败定位

无框：检查 YuNet 模型、正脸大小和逆光；默认模型得分门槛为0.8。无人误框：保留真实图像和 backend，不把家具框计作人脸通过；检查是否退到 Haar。框正常但不动：检查运动开关、串口状态、是否已居中或正在致意。手动运动会暂停自动跟随并保留识别，重新启动跟随恢复；致意结束不应切回手动。俯仰方向相反时记录相机安装方向，可用模式参数 `pitch_direction:-1` 对照。
