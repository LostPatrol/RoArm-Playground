# 视觉标记寻宝

现场状态：**待实测**。最终结论统一以 [状态表](../status.md) 为准；本文列验收方法，不预先宣布通过。

## 目的

检测真实 AprilTag tag36h11 编号并引导机械臂朝标记方向转动，展示可编码视觉目标。

## 所需物品与前置

AprilTag tag36h11 纸质标记，保留白边，推荐初测边长约8–12cm；OpenCV需含 `aruco.DICT_APRILTAG_36h11`。与本机 `ros2-ardupilot-sitl-hardware/correction_service` 使用同款family；旧4×4 ArUco纸张不再适用。

## 网页操作

1. 打开“标记寻宝”，展示第一个tag36h11标记，核对编号和画面四边形边界。
2. 替换为不同编号，确认不是沿用旧值。
3. 在允许的扫描扇区内藏标记后启动搜索；出现后观察亮灯、编号和水平/俯仰跟随。
4. 遮住/移走标记，再测试寻找；点击停止。

## 通过标准

显示编号来自真实解码，普通二维码不误当tag36h11；发现目标后大致朝其方向并亮灯，边界随纸张移动，保持识别模式以免边界冻结。移走后清除框，停止后不追加扫描；无需精确指向纸张中心。本功能不计算3D位姿。

## 自动测试

在项目根目录使用项目 `.venv/bin/python`。

运行 `.venv/bin/python -m unittest discover -s tests -p test_vision.py -v`，自动生成并解码编号 17，验证归一化中心。

## 现场未验收

打印大小、倾斜距离、遮挡与实体扫描空间待实测；不能宣称底座已完成全周扫描。

## 失败定位

无编号：检查字典、白边、打印清晰度和反光；提示缺 ArUco 时核对 OpenCV contrib。方向错误：检查实际目标框和底座符号；调整扫描范围须服从现场线缆空间。
