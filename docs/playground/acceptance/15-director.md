# 自然语言机器人小导演

现场状态：**待实测**。最终结论统一以 [状态表](../status.md) 为准；本文列验收方法，不预先宣布通过。

## 目的

用真实本地语言模型把中文要求转成受限动作预览，再明确运行生成程序。

## 所需物品与前置

按 [host.md](../host.md) 下载并运行本地 GGUF 语言模型服务；后端配置 --director-url 与模型名。资源占用和速度须在演示笔记本测量。

## 网页操作

1. 打开“语言导演”，输入“向左看一下，开灯，再打招呼”。
2. 请求生成预览，查看步骤、中文说明和每步参数；生成期间机械臂不动作。
3. 点击执行预览，观察真实动作和事件；停止后检查不追加后续动作。
4. 输入超出当前能力的要求，如抓未知物体；检查明确说明或拒绝。
5. 停模型服务后测试错误提示。

## 通过标准

动作来自实际 LLM 请求，预览和执行分开；受限动作经校验，服务失败不回退成预写脚本冒充模型。实体按预览顺序大致运动即可。当前模型动作集合支持关节/灯光/等待/致意，识别人和抓取等扩展须以最终实现为准。

## 自动测试

在项目根目录使用项目 `.venv/bin/python`。

运行 `.venv/bin/python -m unittest discover -s tests -p test_host_worker.py -v`，验证 HTTP 路径、JSON校验和只预览；该套件模拟模型响应。另用项目 Python 运行 `-m host.director '灯亮'` 连接真实模型，保存响应和耗时。

## 现场未验收

演示笔记本真实模型速度、内存、中文计划质量、实体执行和服务失败恢复待实测。

## 失败定位

无预览：查模型端口、--director-url 和日志；格式错误：记录原始输出并保留校验失败。动作语义反向：核对提示词与实际夹爪/底座符号。不要将 mock 模型响应报告为真 LLM 推理。
