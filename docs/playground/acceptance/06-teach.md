# 动作示教、记忆与回放

现场状态：**待实测**。最终结论统一以 [状态表](../status.md) 为准；本文列验收方法，不预先宣布通过。

## 目的

用网页摆姿态并记录真实反馈，保存多个姿态后重演动作。

## 所需物品与前置

串口连接并有四关节实测反馈；工作空间能容纳几个简单姿态。采用网页示教，不通过关闭力矩手动拖动承重机械臂。

## 网页操作

1. 打开“动作示教”，输入独立程序名称。
2. 用关节 ±5° 控制摆出姿态，等待实体停稳，点击记录。
3. 再做两个姿态并分别记录；确认列表累计三个姿态。
4. 回放该程序，观察真实机械臂按顺序移动；中途停止。
5. 刷新网页后检查程序仍在，重新回放。

## 通过标准

每次记录来自串口 read 返回的真实角度；保存和刷新后内容一致；实体能按相同顺序重现大致姿态。停止后不执行后续姿态；无需精确回到每个目标角度。

## 自动测试

在项目根目录使用项目 `.venv/bin/python`。

运行 `.venv/bin/python -m unittest discover -s tests -v`，结合程序保存/读取和串口模拟测试；自动测试只验证数据与调度。现场可导出 /api/state 的 programs 与 arm，核对记录和实测。

## 现场未验收

多个姿态实机回放、重启持久化、中途停止及空间适配待实测。

## 失败定位

记录失败：查看串口反馈而非目标值。记录数不符：检查程序名称及数据目录写权限。回放停顿：查看连接中断、3°等待超时事件；超时不能改写成精确到位。

记录日期、软件版本、输入物品/人员、实际效果与失败现象；保存关键状态、截图或录像，不把自动测试结果替代实体证据。
