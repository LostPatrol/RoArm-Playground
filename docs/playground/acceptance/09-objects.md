# 常见物品识别与竞猜

现场状态：**待实测**。最终结论统一以 [状态表](../status.md) 为准；本文列验收方法，不预先宣布通过。

## 目的

让真实 YOLO 神经网络识别常见物体，讨论类别和置信度的局限。

## 所需物品与前置

按 fetch_vision_models.sh 下载 SHA256 已核验的 YOLOX-Nano；准备瓶子、杯子、书、手机等 COCO 类物品，背景尽量干净。

## 网页操作

1. 打开“物品识别”，核对模型和后端可用。
2. 每次展示一件物品，先猜类别，再观察框、类别和置信度。
3. 展示两件物品，观察实际检测是否分开；换成模型类别外的物品。
4. 连续运行一分钟，记录推理耗时和视频连续性。

## 通过标准

至少准备好的演示物品能被实际模型识别；框、标签与输入图对应，失败时如实记录。无模型明确报错；物品识别不自动驱动机械臂。不能把每件物品都必须正确作为未经过数据验证的承诺。

## 自动测试

在项目根目录使用项目 `.venv/bin/python`。

运行 `.venv/bin/python -m unittest discover -s tests -p test_vision.py -v`。可用 `ROARM_VISION_REAL_IMAGE=<YOLOX官方dog.jpg>` 验证 dog/bicycle 真推理；否则该用例跳过。

## 现场未验收

板端连续 CPU 推理速度、真实物品距离与准确率待实测；本机参考图成功不表示板端吞吐已通过。

## 失败定位

缺模型：检查模型目录和文件 SHA256；加载错误：核对 OpenCV和模型版本。误报：调整阈值和场景，检查物体是否属于 COCO。卡顿：降低识别频率，同时检查原视频是否正常。
