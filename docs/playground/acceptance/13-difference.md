# 机器人找不同

现场状态：**待实测**。最终结论统一以 [状态表](../status.md) 为准；本文列验收方法，不预先宣布通过。

## 目的

用固定视角前后画面的实际差异框找出物品移动或移除区域。

## 所需物品与前置

稳定光照与桌面物品；机械臂和摄像头必须保持同一姿态。此模块检测像素变化，不自动说出物体语义。

## 网页操作

1. 打开“找不同”，拍基准照片。
2. 移动或拿走一件物品，保持相机不动，再点击比较。
3. 检查变化框和 changed_fraction；用未变化场景再次比较。
4. 故意改变光照或机位，观察误报并重新拍基准。

## 通过标准

实际变化区域被框出；相同照片不产生变化。物品拿走后的原位置也应算变化；光照/机位变化要解释为前置条件破坏。无需运动精度指标，因为比较时不应运动。

## 自动测试

在项目根目录使用项目 `.venv/bin/python`。

运行 `.venv/bin/python -m unittest discover -s tests -p test_vision.py -v`，检查变化框中心、相同图无变化和尺寸不匹配错误。

## 现场未验收

真实自动曝光、灯光、桌面反光和视频振动对结果影响待实测。

## 失败定位

先提示无基准：先拍基准；全图变化：检查相机是否移动或曝光是否变。微小变化无框：检查阈值与面积过滤。停止不等于机位完全一致，必须观察实际画面。
