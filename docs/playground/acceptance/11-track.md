# 点击框选目标并追踪

现场状态：**待实测**。最终结论统一以 [状态表](../status.md) 为准；本文列验收方法，不预先宣布通过。

## 目的

将用户框选区域作为真实图像模板，验证后续图像匹配及明确丢失状态。

## 所需物品与前置

有纹理的物品、稳定距离、简单背景；目标至少 8×8 像素。不要只框纯色内区，应带可辨别边缘。

## 网页操作

1. 打开“框选追踪”，在视频画面拖出框，确认框选结果，点击“跟踪选中目标”。当前该按钮会同时启用水平随动，先在小范围内测试。
2. 缓慢平移物体，对照检测框和实际底座运动；点击“停止跟踪”退出。
3. 完全移出目标，检查 lost 提示和框清除。
4. 大幅旋转、改变距离后观察失效；重新框选恢复。
5. 选择无纹理区域，确认明确提示。

## 通过标准

跟踪位置随实际模板像素平移；匹配不足时不保留旧检测，停止基于旧目标继续运动。机器人只需大致转向，不要求精确跟踪；尺度和旋转失败如实显示。

## 自动测试

在项目根目录使用项目 `.venv/bin/python`。

运行 `.venv/bin/python -m unittest discover -s tests -p test_vision.py -v`，验证随机纹理真正移位后的框位置、无目标丢失、无纹理拒绝。

## 现场未验收

浏览器拖框归一化、真实背景误锁、随动摄像头尺度变化待实测。

## 失败定位

框选位置不对：检查视频画面显示比例与归一化值。纯色失败属于不可追踪输入；重复纹理误锁需重新框。分辨率改变后必须重新选目标。
