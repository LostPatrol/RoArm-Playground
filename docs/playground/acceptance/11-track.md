# 点击框选目标并追踪

现场状态：**待实测**。最终结论统一以 [状态表](../status.md) 为准；本文列验收方法，不预先宣布通过。

## 目的

将用户框选区域作为真实图像目标，验证光流移动跟踪、多尺度模板重捕获及明确丢失状态。

## 所需物品与前置

有纹理的手持物品、简单背景；目标至少8×8像素。不要只框纯色内区，应带物品可辨别边缘而少框背景。板端使用现有OpenCV前后向光流/RANSAC，不需要CSRT或新增模型。

## 网页操作

1. 打开“框选追踪”，在视频画面拖出框，确认框选结果，点击“跟踪选中目标”。该按钮启用双轴随动，先在小范围内测试。
2. 手持物体连续平移、适度靠近/远离、缓慢旋转，对照框与底座/肘部运动；手动调关节应保留识别并暂停自动运动。
3. 完全移出目标，检查 lost 提示和框清除。
4. 再把目标放回视野，观察多尺度模板重捕获。停止或切换其他项目后不应残留选择框/检测框。大幅翻面/快速运动模糊失效时重新框选。
5. 选择无纹理区域，确认明确提示。

## 通过标准

跟踪位置随实际模板像素平移；匹配不足时不保留旧检测，停止基于旧目标继续运动。机器人只需大致转向，不要求精确跟踪；尺度和旋转失败如实显示。

## 自动测试

在项目根目录使用项目 `.venv/bin/python`。

运行 `.venv/bin/python -m unittest discover -s tests -p test_vision.py -v`，验证真实像素多帧平移、缩放、旋转、近期模板更新；模拟无CSRT并明确执行光流分支，遮挡后lost/零置信度，再出现目标时重捕获。自动图像序列不代替真人手持实物验收。

## 现场未验收

浏览器拖框归一化、真实背景误锁、随动摄像头尺度变化待实测。

## 失败定位

框选位置不对：检查视频画面显示比例与归一化值。纯色失败属于不可追踪输入；重复纹理误锁需重新框。分辨率改变后必须重新选目标。
