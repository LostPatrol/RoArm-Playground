# 实测基线

以下为 2026-10-08 的历史实机记录，本次仓库整理没有重新执行运动或更改设备。原始 JSON、照片、截图与报告保留在开发机的 `rk3588/system-test/` 和 `agent/`。

## 视频与连接

设备为 rd-rk3588，Ubuntu 20.04.6 / aarch64 / Linux 5.10.198，约 15 GiB 内存。UQ212 USB 摄像头与 RTL8822CU 网卡接 05e3:0610 USB-A Hub，RK3588 使用独立 12V/2A 电源。

拔掉本机 Type-C 数据线后，视频连续 60.03 秒收到 897 帧，14.94 fps；机械臂只读反馈 80/80 成功，中位延迟 114.0 ms。集成同屏控制后，30.05 秒收到 447 帧，14.87 fps；只读反馈 40/40 成功，中位延迟 110.8 ms。

桌面与手机宽度经过真实 Chrome 检查。摄像头 USB 驱动解绑/重绑后采集及浏览器恢复；模拟 sysfs 测试验证换端口/节点发现，没有完成实物换 Hub 口验收。

当轮标准要求目标与回位误差均小于 0.5°；四轴能运动，但前三轴未达到该标准。后续普通应用不以高精度为验收要求。此前两次底座 1° 测试没有测到位移，记录未删除；没有调整 PID、力矩或 DEFA。

原生网页底座按钮按住 0.3 秒产生约 7.65° 位移。T123 停车停止增量目标，仍存在运动余量；轴 0 不能用于停车，需要逐轴 1–4 发送停止。松键/失焦和页面退出的请求处理已实现，完全断网时送达没有保证。

## 未解决与未实现

- 新 Hub 完全断电后，网卡从光盘模式自动联网尚未实测，不能声称无人干预冷启动已通过。
- 旧 Type-C Hub 曾导致设备不可达，原因未确定，当前接法使用 USB-A Hub。
- 角度误差原因未确诊；Torque OFF、DEFA、坐标运动及拖拽未实机验收。
- ROS 2 集成、识别抓取、手眼标定、语音及 IMU 随动尚未实现。
- NPU 只验证现有 MobileNet 单图能执行，约 2.40–3.22 ms，未验分类准确率或端到端吞吐。
- 摄像头随夹爪朝前；抓取需要另行确定观察姿态、相机与夹爪关系及桌面几何。底座有限角域不代表支持无限旋转。
