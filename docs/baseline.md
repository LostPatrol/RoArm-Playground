## task01历史记录（2026-10-08）

以下保留task01的视频、HTTP控制和精度测试事实，不代表task02当前连接方式或能力状态。原始JSON、照片、截图与报告保留在开发机 `rk3588/system-test/` 和 `agent/`。

### 视频与连接

设备为 rd-rk3588，Ubuntu 20.04.6 / aarch64 / Linux 5.10.198，约 15 GiB 内存。UQ212 USB 摄像头与 RTL8822CU 网卡接 05e3:0610 USB-A Hub，RK3588 使用独立 12V/2A 电源。

拔掉本机 Type-C 数据线后，视频连续 60.03 秒收到 897 帧，14.94 fps；机械臂只读反馈 80/80 成功，中位延迟 114.0 ms。集成同屏控制后，30.05 秒收到 447 帧，14.87 fps；只读反馈 40/40 成功，中位延迟 110.8 ms。

桌面与手机宽度经过真实 Chrome 检查。摄像头 USB 驱动解绑/重绑后采集及浏览器恢复；模拟 sysfs 测试验证换端口/节点发现，没有完成实物换 Hub 口验收。
