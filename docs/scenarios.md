# 演示路线

项目用于向初中生演示借助 Agent Vibe Coding 实现机械臂互动功能，鼓励他们学习使用 AI。目标是直观、有趣的现场表演，不要求生产环境级稳定性，也不以高精度运动为前提。多种场景可以共存。

当前统一网页已建立18项入口及对应软件路径。具体操作见[18份验收手册](playground/README.md)，实体证据与未完成项见[当前状态](playground/status.md)。建议从直接可见的感知/动作逐步演示到编程与模型导演，每次只启动一个运动模式：

| 场景 | 当前演示内容与边界 |
|---|---|
| 机器人的眼睛 | 人脸、颜色、ArUco、常见物品、框选跟踪；真实模型/图像已有测试，颜色目标实物跟随已有证据，真人互动和现场准确率仍需验收 |
| 手势与猜拳 | MediaPipe真实样本识别、游戏规则与动作入口；张手样本低于阈值，真人手势链路待验收 |
| 语音与拍手 | 网页自动启动板端音频worker；Vosk真实中文样本成功，启停心跳已实测；真人口令/拍手及噪声适应待验收 |
| 示教与积木编程 | 保存真实关节姿态、回放、重复与条件动作；已有实体回放，学生编排节目待现场演示 |
| 摄影与三维 | 四张实物照片拼接、固定视角找不同、真实关节反馈驱动三维几何示意；全班/大角域全景与末端尺寸标定未验收 |
| 自然语言导演与Agent改规则 | 真Qwen1.5B CPU生成计划，预览后明确执行；基础语义与实际小幅动作已有证据，复杂措辞及4060/CUDA未测，现场Agent修改规则演出待验收 |
| 黑色泡沫抓取 | 已在观察姿态看到并框出泡沫，提供人工示教定点尝试；尚无夹起离桌证据，标“正在开发” |
| ESP32＋IMU头部随动 | 协议、校准与模拟输入演示；硬件、固件与真人头戴尚未验收，标“正在开发” |

摄像头随夹爪移动，桌面识别与找不同需要合适观察姿态；底座有限角域不代表无限旋转。ROS 2 SDK属于可选后续扩展，目前未集成，不作为以上功能的前置条件。task01早期可行性与精度测试保留在[历史基线](baseline.md)。
