# 演示方向

项目用于向初中生演示借助 Agent Vibe Coding 实现机械臂互动功能，鼓励他们学习使用 AI。目标是直观、有趣的现场表演，不要求生产环境级稳定性，也不以高精度运动为前提。多种场景可以共存。

以下均为后续设想，当前仅完成视频、网页控制、运动测试与开发可行性评估：

| 场景 | 预期演示 |
|---|---|
| 视觉抓取 | 通过摄像头和 CV/神经网络识别桌面黑色泡沫立方体，尝试用夹爪抓取 |
| 人脸扫描 | 底座转动观察周围，识别人脸后点亮 LED；实际扫描范围需考虑线缆与障碍 |
| 语音控制 | 通过简单口令控制机械臂运动 |
| 头部随动 | ESP32 + IMU 测量头部转动，让机械臂摄像头大致跟随，本机显示画面 |
| ROS 2 扩展 | 评估厂家 SDK 的模型、规划与控制能力，结合现有网络连接逐步集成 |

本次仓库整理未实现这些后续功能。当前可用内容及未通过的实测项见 [baseline.md](baseline.md)。
