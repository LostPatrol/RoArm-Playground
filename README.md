# RoArm-Playground

RoArm-Playground 是一个基于 **RoArm-M2 机械臂与 RK3588** 的互动实验项目，将机器视觉、手势与语音识别、动作编程和本地语言模型连接到真实机械臂。通过统一的网页工作台，可以观察摄像头画面、控制机械臂、编排动作，也可以尝试让机器人跟随目标、回应手势或执行自然语言生成的动作计划。

项目提供 **18 项互动实验入口**，把“感知 → 判断 → 动作”的过程呈现在同一个界面中，便于探索 AI 与机器人如何协作。

## 项目功能

### 视觉识别与跟随

| 功能 | 可以做什么 |
|---|---|
| 寻找观众、亮灯致意 | 检测画面中的人脸，转向目标并用灯光和动作打招呼。 |
| 彩色指挥棒 | 识别指定颜色，让机械臂随彩色目标的移动调整朝向。 |
| 视觉标记寻宝 | 识别 AprilTag 标记及编号，用标记触发转向、亮灯等动作。 |
| 常见物品识别与竞猜 | 在画面中标出模型识别到的物品类别，结合识别结果开展互动。 |
| 点击框选并追踪 | 在视频中框选目标，持续追踪它在画面中的位置。 |

### 手势、声音与游戏

| 功能 | 可以做什么 |
|---|---|
| 手势遥控 | 将识别到的手势映射为机械臂动作。 |
| 中文语音控制 | 识别中文口令，触发对应的运动或灯光指令。 |
| 拍手导演与节奏律动 | 将拍手节奏转换为动作与灯光变化。 |
| 和机器人猜拳 | 识别猜拳手势、判断胜负，并给出互动反馈。 |

### 动作编排与三维交互

| 功能 | 可以做什么 |
|---|---|
| 动作示教、记忆与回放 | 记录机械臂的实际姿态，保存多个动作并按顺序回放。 |
| 图形化动作编程 | 用动作积木组合关节运动、灯光、等待、重复和条件判断。 |
| 真实反馈驱动的三维机械臂 | 根据实测关节角显示三维姿态，也可以拖动模型中的夹爪发出位置指令。 |

工作台同时提供四轴关节与灯光滑条、坐标控制和原厂命令入口。手动调整姿态时可以继续观察视觉检测结果；停止按钮用于取消程序与持续运动，并尝试保持实测姿态。

### 摄影与画面比较

| 功能 | 可以做什么 |
|---|---|
| 全景摄影师 | 控制机械臂转向多个角度拍摄，再将照片拼接成全景图。 |
| 找不同 | 在固定观察姿态下比较前后画面，标出发生变化的区域。 |

摄像头支持实时视频、快照和分辨率切换，方便一边观察一边调整实验。

### 自然语言与规则创作

| 功能 | 可以做什么 |
|---|---|
| 自然语言小导演 | 用本地 Qwen 语言模型将中文描述转换为动作计划，先预览，再确认执行。 |
| 现场 Agent 改规则 | 结合项目源码与规则参数，借助 AI 编程助手修改互动逻辑，再运行验证。 |

### 正在开发的实验

| 功能 | 当前进展 |
|---|---|
| 黑色泡沫识别与抓取尝试 | 已提供暗色轮廓检测与示教抓取流程，尚未完成可靠夹起物体的实测。 |
| ESP32＋IMU 头部随动 | 已提供数据接口、校准和模拟输入流程，实物传感器与头部随动仍待验证。 |

## 如何使用

部署并启动服务后，在浏览器中打开 `http://<RK3588地址>:8080/`，选择实验卡片，再点击“启动实验”。网页集成了实时视频、当前实验、三维机械臂与关节控制。

控制链路为 **浏览器／上位机 → Wi-Fi → RK3588 → USB 串口 → 机械臂**。RK3588 负责视频、轻量视觉和中文语音，上位机负责手势识别与可选的本地语言模型。网页运行不依赖 ROS 2。

18 项入口已建立，部分功能已有实体测试，完整现场互动仍在持续验证。机械臂存在到位误差，三维显示用于观察姿态，普通互动以可见运动效果为主。**截至 2026-10-09，当前设备处于舵机通信故障诊断阶段，生产服务已停止**，详情见[设备诊断说明](docs/servo-diagnostics.md)。各项功能的验证进展见[当前状态](docs/playground/status.md)。
