# 第 0 章 导览：这门课想让你获得什么

> 本章目标：用十分钟看清整门课的地形——它由哪几块组成、每块解决什么问题、你该按什么顺序读、以及哪些内容只需知道入口而不必现在掌握。

## 0.1 一句话定位

这门课不是"AI 原理课"，也不是"提示词大全"。它想解决的是同一个问题在三个层面的版本：

- **认清**：你面前这套东西，哪些是模型、哪些是产品、哪些是你自己写的程序；
- **用好**：把任务说清楚，把结果验证掉，把上下文管住；
- **做出来**：在有限时间里，交付一个能运行、能验收、说得出限制的作品。

"AI + VibeCoding"这个标题里，重心在后者。模型会一直换代，接口会一直改；而"把需求拆清楚、把结果验掉、把版本留住"这套动作，换十代模型仍然成立。

## 0.2 六条主线

全课程围绕六条线展开，每一章都至少落在这六条之一上：

| 主线 | 要回答的问题 | 主要章节 |
|---|---|---|
| 它是什么 | 模型、产品、API、Agent、普通程序的区别 | 1、3、4、5 |
| 它怎么算 | token、注意力、生成、训练与推理 | 2、3、4 |
| 怎么拿到 | 订阅、API、本地部署、成本与合规 | 6、10 |
| 怎么说话 | 目标/背景/限制/验收，迭代与纠错 | 7、9 |
| 怎么不信错 | 幻觉分类、证据等级、四级验证 | 8、12 |
| 怎么交付 | 项目路径、验收标准、能力边界 | 11、12、13 |

一条经验：**初学者最容易停在"它是什么"，从业者最容易跳过"怎么不信错"。** 这门课把后者放在与前者同等的位置。

## 0.4 四条学习路径

不同的人该有不同的读法。

- **零基础学生（12 学时）**：0 → 1 → 4 → 5 → 6 → 7 → 8 → 9 → 11 → 12。第 2、3 章当字典查，第 10 章选读。
- **有编程基础、想尽快上手**：0 → 4 → 5 → 7 → 8 → 9 → 11 → 12。原理章可先跳过，遇到不懂的词回查第 2 章。
- **教师备课**：0 → 13 → 各章"课后题"→ 12。先看课表与评分，再决定哪些章精讲、哪些留给学生自读。
- **只想了解 AI 是什么**：0 → 1 → 4 → 10 → 11.7。约两小时。

## 0.5 首期要求与后续方向

课程面向的是"会用 AI 做事"而非"会训练模型"。下表说明每个主题在首期要求做到什么程度，以及后续可以往哪走。

| 主题 | 首期要求 | 后续方向 |
|---|---|---|
| AI 模型类型 | 认识文本、语音、图像等任务；亲手完成少量实验 | 更多模型选型与组合 |
| 与 AI 对话 | 说明目标、背景、限制、完成标准；根据结果继续修改 | 复杂任务规格与评测 |
| 幻觉、知识不足、不遵守 | 能区分现象，知道要查资料、补条件或实际测试 | 系统化评测与约束机制 |
| Transformer | 用直观例子认识 token、信息关联、逐步生成；不考公式 | 注意力计算、模型结构 |
| 文件、程序与少量代码 | 会保存和运行，能理解并修改参数、简单规则 | 变量、函数、状态、模块 |
| Coding Agent | 在限定项目中完成小改动，检查结果并保留版本 | 更独立的项目开发 |
| 上下文管理 | 提供当前需求和有效信息，整理简短交接记录 | 压缩、检索、持久状态 |
| Harness | 先实践"一次一改、执行检查、权限限制、失败停止" | 显式配置与设计 Harness |
| Subagent、MCP | 选讲或演示，不作全员考核 | 工具配置、分工与通信 |
| API 与计费 | 理解"程序向服务发送请求"；教师演示用量 | 独立调用、错误处理、预算控制 |
| 本地模型 | 在预配置环境中启动、换输入、复现与观察 | 从零安装、量化、服务化 |
| Hugging Face、GitHub | 知道用途，在指定页面查找必要信息 | 独立找模型、读文档、管代码 |
| 网络访问、账号与订阅 | 主要由教师课前处理；保留必要的连接与排障解释 | 获授权环境中的服务配置 |
| 图像、视频生成 | 演示或选修，不要求全员本地部署 | 专项模型实验 |
| 机械臂、ESP32、随动视觉 | 首期可以展示，不作为共同毕业项目 | 独立硬件课程 |

读这张表的方式：**左列是必须会，右列是知道了有用但不必现在会。** 考试与验收只看左列。

## 0.6 这门课不教什么

说清楚边界，比列大纲更重要：

- 不教训练大模型，不教微调，不要求会推导反向传播；
- 不教数学证明，第 2 章只给直觉；
- 不承诺"学完能靠 AI 独立做出任何软件"，第 11 章会讲清楚能力的边界在哪里；
- 不推荐具体服务商、不承诺任何价格，价格与可用性以官网为准；
- 不提供绕过地区限制或规避付费的方法，第 6 章只讲合规渠道。

## 0.7 怎么用这些材料

课程材料有两份，内容一致但用法不同：

**Markdown 讲义**适合精读与打印。每章独立成篇，可以直接用 Typora 配上偏纸张质感的主题导出 PDF；章节末尾的课后题是留给你的，不是装饰。

**配套网站**适合课上演示与随时查阅。除了同样的章节正文，它还提供几样纸质材料做不到的东西：

- **可动手的小实验**：分词与成本估算、梯度下降、注意力热力图、上下文预算表、Agent 循环与故障注入、量化体积估算；
- **章末自测**：每章配题，答完立即给解释；
- **章节内目录与检索**：长文档里快速定位。

网站可以公网访问，也可以在演示机上从仓库直接跑起来（见站点根目录的说明）。断网时以本地运行的版本为准——课堂不该依赖现场网络。

> 要点：讲义回答"为什么"，网站回答"试一试"。两者读同一个知识，但一个用文字说服你，一个让你自己看见。

## 0.8 开始之前

如果你现在只想做一件事：打开第 1 章，读 1.1 节那张"八级台阶"的图。它会在后面十章里反复出现；等你读完第 12 章再回来看，会发现每一级台阶都对应着项目里的一层代码。

准备好了就翻页。

## 课后题

1. 用一句话说出你学这门课最想解决的一个具体问题（不是"想了解 AI"）。
2. 按 0.4 的四条路径，给自己选一条，并写下你打算跳过哪些章、为什么。
3. 对照 0.5 的表，勾出你已经会的三行和完全不会的三行。
4. 思考题：0.6 列了五条"不教"。你认为其中哪一条最容易被误解为"这门课不专业"？为什么？
