A.1 模型与任务

术语一句话解释章节
模型（Model）一组从数据里学出来的参数，给定输入产生输出1
参数 / 权重模型内部可调的数字，训练就是调它们2、3
推理（Inference）用训练好的模型算一次结果，不改参数3、4
训练（Training）用数据反复调整参数，让输出更接近期望3
LLM（大语言模型）以文本为输入输出、参数量很大的模型1、4
多模态（Multimodal）能处理两种以上输入或输出形式（如文字+图片）10
ASR（语音识别）音频 → 文本10
TTS（语音合成）文本 → 音频10
目标检测（Object Detection）图片 → 框 + 类别10
分割（Segmentation）图片 → 每个像素属于什么10
Embedding（嵌入）把文字/图片变成一串数字向量，便于比较相似度2、10
分类 / 回归输出离散类别 / 输出连续数值3
聚类没有标签，把相似的数据分到一起3

A.2 数学与训练

术语一句话解释章节
向量 / Tensor一串数 / 多维数组，是模型运算的基本单位2
梯度下降沿着"让误差变小"的方向一小步一小步调整参数2
学习率每步走多大；太大越过最优，太小走不动2
损失（Loss）衡量输出与期望差多少的数字2
反向传播（BP）从误差倒着算出每个参数该往哪调2、3
激活函数给网络加入非线性，否则多层等于一层3
卷积（Convolution）用小窗口在图上滑动提取局部特征3
过拟合 / 欠拟合训练集太好、新数据很差 / 两边都差2、3
超参数训练前人为设定的值（学习率、层数等）2
迭代 / Epoch更新一次参数 / 把训练集完整过一遍2、3
有监督 / 无监督 / 半监督有标签 / 无标签 / 少量标签3
强化学习（RL）通过奖励与试错学习策略3
CNN / RNN / LSTM卷积网络 / 循环网络 / 带门控的循环网络3
Transformer以注意力为核心的网络结构，现代 LLM 的基础4
注意力（Attention）计算每个词该"看"其他哪些词、看多重4
位置编码告诉模型词的先后顺序4
预训练 / SFT / RLHF大规模学语言 / 学按指令回答 / 按人类偏好调整4
LoRA只训练一小部分附加参数的低成本微调方法10
量化（Quantization）用更少的位数存参数，换更小的体积和更快的速度10
蒸馏（Distillation）用大模型的输出教小模型10

A.3 使用与产品

术语一句话解释章节
Token模型处理文本的最小单位，约等于一个词或半个词4
上下文窗口模型一次能"看到"的 token 总量上限4、9
Temperature控制输出随机性；低更稳，高更多样也更易跑偏4
Top-p只在概率最高的一部分候选里采样4
系统提示 / System Prompt在对话最前面设定角色与规则的文字5、7
API程序调用服务的接口，按用量计费6
API Key调用凭证，等同密码，泄露即被盗用6
订阅按月付费使用聊天产品，通常不含 API 额度6
中转站第三方转售 API 的服务，便宜但存在隐私与稳定性风险6
本地部署把模型跑在自己的机器上，数据不出本地6、10
GGUF一种常见的本地模型文件格式10
显存（VRAM）显卡上的内存，决定能跑多大的模型10
Benchmark标准测试集上的分数，只说明部分能力10
Hugging Face模型与数据集的公共托管平台6、10

A.4 Agent 与工程

术语一句话解释章节
Agent（智能体）能调用工具、多轮执行直到完成目标的模型程序5
工具调用（Tool / Function Calling）模型输出结构化请求，由程序真正执行5
循环（Loop）观察 → 决策 → 行动 → 再观察，Agent 的基本形态5
MCP让 Agent 以统一方式接入外部工具与数据的协议5
SKILL打包好的可复用操作说明与脚本，按需加载5
Harness（脚手架）围绕模型的一整套工程约束：指令、权限、测试、日志5
上下文污染无关或错误的信息进入上下文，带偏后续输出9
交接摘要换新会话时给下一轮的状态说明9
RAG（检索增强生成）先检索资料，再让模型基于资料回答9
子代理（Subagent）由主 Agent 派出的独立执行单元，有独立上下文9
幻觉（Hallucination）输出流畅但与事实不符4、8
知识过时模型训练数据早于当前事实8
不遵守（Instruction Following 失败）明知要求却没照做8
Eval（评测）用固定题目与标准衡量输出质量8
VibeCoding以自然语言驱动 Agent 完成开发的实践方式11
回滚（Rollback）把代码或数据恢复到之前的版本9、13
限位 / 急停硬件运动范围的硬性约束与立即停止手段12
