Offline

课堂上没有网络怎么办

整个站点是纯静态文件，没有后端、没有外部字体、没有 CDN。把 site/ 目录拷到演示机，起一个本地服务即可。

在本机运行

在仓库根目录执行下面两行，浏览器打开提示的地址。断开 Wi-Fi 也照常可用。

python tutorial/tools/build_docs.py
python -m http.server 8080 --directory tutorial/site

第一条只在改过 Markdown 后需要。站点里所有脚本都是相对路径，也可以直接双击 site/index.html 打开；本地服务的好处是地址栏更短、行为更接近线上。

重新导出 PDF

构建脚本用本机已安装的 Chrome 或 Edge 无头模式导出，不依赖任何 Python 包。

python tutorial/tools/build_docs.py --pdf

导出的是 site/print/ 下的打印版页面，与网页版内容一致、版式更紧凑。没有浏览器时会跳过并提示，不影响网页构建。

Plain text

原始 Markdown

如果你要在 Typora 里改、在别的编辑器里批注，或想自己换排版，直接取源文件。主题建议用纸感浅色系，不要用深色背景打印。

源文件在仓库的 tutorial/ 目录下，文件名即章号：00-course-map.md 到 13-teaching-and-assessment.md，另加 appendix-a-glossary.md 与 appendix-b-resources.md。

每章开头一行 HTML 注释说明本章用途，正文以一级标题开始，末尾统一是 ## 课后题。改完重新执行构建即可，无需改脚本。
